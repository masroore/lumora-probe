# Lumora Probe v0.1.0

**Release date:** 2026-07-31  
**Distribution:** `lumora-probe`

## Release summary

Lumora Probe v0.1.0 is the first GA release of the engineering observability
platform. It provides capture, replay, analysis, reporting, study/image inspection, plugin
extension, and operational packaging for trusted DICOM engineering environments.

## Included capabilities

- Association and relay observation with ordered event streams and protocol traces.
- Durable capture evidence, retention/ring-buffer handling, replay, and golden-fixture checks.
- Study Browser, Metadata Inspector, Transfer Inspector, Event Timeline, and image viewer.
- Deterministic analysis rules and report/handover exports with redaction controls.
- REST/OpenAPI and WebSocket interfaces, health/readiness, metrics, audit, and read-only mode.
- Trusted plugin SDK and bundled plugin lifecycle.
- Accessibility hardening, local-only committed assets, offline/no-Node installation, and a
  non-root single-volume Docker image.
- Scheduled external interoperability validation against DCMTK 3.6.8, dcm4che 5.33.1, and
  Orthanc 24.5.1, with a five-syntax transfer matrix.
- Probe Lite and Sender Lite cross-platform CLI utilities, including stdout JSONL logging,
  UID-safe storage, deterministic Study Batch cataloging, and trusted-network exit contracts.

## Known limitations

This release is not a PACS, RIS, EMR, diagnostic workstation, or clinical archive. It has
no built-in authentication/RBAC, no PS3.15 de-identification conformance, no plugin sandbox,
and cannot observe C-MOVE C-STORE sub-operations unless configured as the destination AE.
See the known-limitations guide before exposing the service beyond a trusted boundary.

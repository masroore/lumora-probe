# ADR-0022: Component-Weighted Testing With Injected Clock and ID Source

- **Status:** Accepted
- **Date:** 2026-07-28

## Context

ADR-0017 introduced three time concepts and ADR-0004 UUIDv7 identity. If those are reached
through bare module-level calls scattered across eight slices, every test asserting on an
event is non-deterministic, and retrofitting injection later is a sweep across the whole
codebase.

`13` also has a shape problem. §4 mandates a pyramid with most tests in the lower layers
and §3 says test at the lowest appropriate layer. But after ADR-0006 the domain is plain
Python with thin behaviour — the bugs in this product are not in our value objects. They
are in pynetdicom's association handling, pydicom's decode of exotic transfer syntaxes,
SQLite under concurrent readers, ADR-0002's thread→loop boundary, and ADR-0007's JSONL
crash recovery. A unit-heavy suite would exhaustively test our own mappers and catch none
of that.

## Decision

**Weighted to component and integration**, recorded as a deliberate deviation from `13`
§4. Thin unit layer on genuinely pure logic (value-object invariants, rule evaluation,
envelope serialization); the bulk at component level with real SQLite, real pydicom, real
filesystem and a real bus, faking only the clock and ID source; real pynetdicom loopback
for the DICOM edge; thin end-to-end over HTTP for the workflows `13` §7 names.

**Requirements landing in Phase 05:**

1. **`Clock` and `IdGenerator` are core protocols, injected, never called directly.**
   `Clock` exposes both wall and monotonic — ADR-0017's split is meaningless if tests can
   freeze only one. Doubles provide a controllable wall clock, a manually advanced
   monotonic counter and a seeded deterministic UUIDv7 sequence. An import-linter contract
   (ADR-0012) bans `time.` and `uuid.` imports outside `core/`, so this is enforced rather
   than remembered.
2. **Golden `.lpcap` fixtures are the regression backbone.** Because ADR-0018 made
   analysis a pure function of (capture, rule-set version) and ADR-0017 made ordering a
   gap-free integer, replaying a fixture yields a byte-comparable event stream and finding
   set. `13` §8's event-contract testing and `01` §9's "replay production captures"
   collapse into one cheap mechanism — and it is the only test shape that catches "we
   changed the bus and the timeline reordered".
3. **Test DICOM is synthetic-only, generated by pydicom, never real patient data — not
   even de-identified.** `13` §14 says anonymized; this goes further. De-identification
   routinely misses burned-in pixel text and private tags, and a repository with leaked
   PHI is unrecoverable. Fixtures are generated by script so they are reviewable as code
   rather than opaque binaries.
4. **Real-implementation interop is opt-in, not in the default gate.** `13` §10 wants
   validation against multiple implementations: DCMTK, dcm4che and Orthanc as Docker-based
   marked suites. Keeping them out of the default gate keeps that gate fast enough to
   actually run — but they must be a **scheduled** job, or §10 quietly never happens.
5. **Crash recovery and drop behaviour get explicit tests**, since both are otherwise
   unverifiable promises: kill mid-capture and assert the torn trailing line is discarded
   and the capture marks `Interrupted` (ADR-0007); saturate a UI channel and assert the
   `sequence` gap matches the `EventsDropped` count (ADR-0002, ADR-0017).
6. **`pytest-asyncio` and `import-linter` are new dev-only dependencies** outside `04`'s
   list, recorded here rather than silently added, per `04` §15.
